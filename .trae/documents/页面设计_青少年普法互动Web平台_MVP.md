# 青少年普法互动Web平台（MVP）页面设计说明（桌面优先）

## 0. Global Styles（多邻国风格参考）
- Layout：桌面优先（≥1200px）内容居中（max-width: 1120px），两侧留白；小屏降级为单列。
- 设计令牌（建议）：
  - Background：#F7F8FA（浅灰）
  - Primary：#58CC02（明绿）
  - Accent：#1CB0F6（蓝）
  - Warning：#FFB020；Danger：#FF4B4B
  - Text：#1F2937；Subtext：#6B7280
  - Card：白底+轻阴影；圆角 16px；间距 8/12/16/24px
- Typography：H1 28/32，H2 20/28，Body 14/22；数字/等级可加粗。
- Button：主按钮绿色填充；Hover 加深 6%；禁用态灰。
- Link：蓝色下划线hover；面包屑/辅助链接用灰。
- 动效：按钮点击压缩 0.98；卡片hover上浮 2px；进度条缓动 200ms。

## 1) 登录/注册页
- Meta：Title「登录｜青少年普法互动平台」；Description「登录后开始闯关学习法律常识」；OG 同步。
- Page Structure：左右分栏（左：品牌与卖点；右：登录卡片）。
- Sections & Components：
  1. 顶部品牌区：Logo + Slogan（“像打游戏一样学法律”）。
  2. 角色切换：Tab（学生/教师），影响登录后跳转与表单提示。
  3. 登录卡片：账号、密码；主按钮“登录”；次按钮“注册/创建账号”；“忘记密码”。
  4. 合规提示：未成年人提示与隐私链接（MVP最小）。
- 交互状态：表单校验、错误提示、加载态、成功后路由跳转。

## 2) 学生主页（学习+闯关+成长+资源）
- Meta：Title「学习中心｜闯关学法」；Description「学习路径、闯关、成长与资源」；OG 可选。
- Layout：顶部导航 + 内容区（左：学习路径；右：成长与任务摘要，桌面双栏；移动端单列）。
- Page Structure：Dashboard 结构（卡片网格 + 列表）。
- Sections & Components：
  1. Top Nav：学习/成长/资源/任务（同页Tab）+ AI按钮；右侧用户菜单（昵称、退出）。
  2. 学习路径区：单元列表（Accordion）+ 关卡卡片（锁定/可学/已完成）；关卡卡显示标题、进度、奖励XP。
  3. 闯关弹出/内嵌关卡：
     - 题干区（情境描述）
     - 选项区（按钮式选项）
     - 提交/下一题
     - 结果反馈（对错、简短解析、法条要点）
  4. 成长摘要卡：等级、XP进度条、徽章（最多3个展示）+ “查看全部”。
  5. 任务摘要卡：教师任务列表（最多5条），显示截止时间与“去完成”。
  6. 资源入口卡：推荐资源3条（按当前单元/搜索历史）。
- 关键可用性：关卡结果强反馈（颜色+文案），保证“继续下一题”路径明确。

## 3) AI助手页
- Meta：Title「AI普法助手」；Description「用对话方式解释概念与推荐学习内容」。
- Layout：左侧会话列表（桌面可见，宽 280px），右侧聊天窗口；移动端隐藏侧栏。
- Sections & Components：
  1. 安全与边界提示条：提示“学习用途，不构成法律意见”。
  2. Chat Window：
     - 消息气泡（用户右、助手左）
     - 加载态（“正在思考…”）
     - 推荐卡片区（资源/关卡卡，点击跳转）
  3. 输入框：多行textarea + 发送按钮；支持快捷键 Enter 发送。
  4. 会话管理：新建会话、清空会话（MVP）。

## 4) 教师后台页
- Meta：Title「教师后台｜班级与进度」；Description「查看进度、布置任务、发布资源」。
- Layout：左侧侧边栏（班级/进度/任务/资源），右侧工作区；桌面优先。
- Page Structure：表格 + 统计卡 + 表单抽屉。
- Sections & Components：
  1. 班级管理：
     - 班级列表（卡片）+ 创建班级按钮
     - 班级详情：加入码、成员表格（姓名/昵称/完成率/最近学习）
  2. 进度看板：
     - KPI卡（活跃学生数、平均正确率、完成率）
     - 可筛选（按单元/关卡）
     - 学生进度表（可排序）
  3. 任务布置：抽屉表单（班级、目标类型level/resource、目标、截止时间）；发布后显示任务列表与完成统计。
  4. 资源发布：资源表单（标题、类型、标签、内容/链接、上传附件可选）；发布后在学生端资源中心可见。
- 交互状态：创建/发布成功 toast；表格加载 skeleton；空状态引导。
